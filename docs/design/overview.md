## 1. 真实场景：用户是怎么问客服的（调研结论）

- 真实电商客服（Shopify Inbox、Tidio Lyro、Gorgias、Intercom Fin）都是：**欢迎语 + 快捷按钮 “Track my order”** → 要订单号 + 邮箱 → Agent 查单 → 自然语言回复（常附物流链接/时间线）。
- 身份校验强弱：登录态 > 一次性验证码 > **订单号 + 邮箱** > 只给订单号。只给订单号最危险，因为订单号是连号，可被人枚举。
- 查不到时统一说“没找到匹配的订单”，**不暴露**是订单不存在还是邮箱不对；多次失败就限制。
- 演示型产品（OpenAI cs-agents-demo、Botpress、Rasa Inspector）普遍是“聊天 + 侧面板展示 Agent 内部过程”：tool 调用、参数、知识命中、guardrail、耗时。
- Vercel AI SDK 的做法：聊天里出现一行“正在查询订单…”，完成后变成结果卡片。

> **大白话**：我们的页面要让人一眼觉得“这就是一个网店客服窗口”，然后右边有一扇“透明玻璃”，能看到客服背后做了什么、花了多少 token。
